# شعبة المعلومات - عين النسر

منصة الرصد والتحليل المعلوماتي التابعة لشعبة المعلومات ضمن **منظومة عين النسر**.

تجمع المنصة تدفقات الأخبار والتنبيهات والبيانات العامة ضمن لوحة تشغيل موحدة لدعم المتابعة والتحليل اللحظي.

## التشغيل

```bash
npm ci
npm run dev
```

يفتح النظام محلياً على `http://localhost:3000`.

## التشغيل الإنتاجي

```bash
npm run build
npm start
```

أو باستخدام Docker:

```bash
docker build -t eagle-eye-information .
docker run --rm -p 3000:3000 eagle-eye-information
```
